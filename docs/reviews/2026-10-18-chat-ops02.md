## 已完成

- 已发送用户/助手气泡编辑、切换有效版本、软删除：HTTP 校验 requestId、预期 revision、字段白名单和版本归属；服务端持久化后刷新历史。冲突不会写入本地编辑结果，也不会自动重算后续气泡。
- 单泡重生成只更新选中助手气泡。**整回合范围**为所选 turn 中当时未删除的全部助手气泡；不含用户、已删除气泡或后续 turn。快照固定目标集合与来源版本，所有目标完整成功后同事务激活；缺任一目标不激活任何新版本。
- 重生成使用稳定 job ID（发起 requestId）、既有操作账本、显式 CAS 和任务状态。并发任务/冲突重试返回 409 `GENERATION_BUSY`。
- 合成生成器按片段写入独立持久表；片段有 job、attempt、seq 和 bubble ID。重复片段幂等，同号不同内容/断序拒绝。不同尝试不拼接旧失败文本。
- 状态为 queued/running/succeeded/failed/unknown/cancelled。为不重写 DATA-01 表，cancelled 存为既有 status=failed、error_code=CANCELLED，并在 API 明确投影。失败不能事后重标为取消；成功不能取消。
- 取消/失败/中断保留部分文本，部分文本不作为普通气泡、当前版本、搜索或记忆证据。running 重启后为 unknown，不自动重调；UI 明确确认后才重试。来源已变更的旧任务不可重试，须重新发起并捕获新来源。
- 首次合成回复也复用该任务/片段机制；原提交端点等待短时假模型任务结束后返回原持久回执。重生成端点立即返回任务 ID，UI 在活动任务期间轮询，终态停止；没有空闲模型轮询。
- v11 长按菜单复用 useLongPress；编辑、版本、删除、单泡/整轮操作走真实隔离 HTTP。客户端先保存不可变操作快照，丢 ACK、刷新后重试原 requestId，历史核验后才释放快照；不会用本地数组冒充保存。
- 复制/局部引用/引用跳转会按当前 revision 请求来源核验。引用来源编辑、切版、删除或撤权后，服务端投影只返回失效占位，不返回旧引用片段；草稿/待提交引用也在展示时核验。未提交气泡尚无来源，不能作为持久引用。
- 搜索/记忆来源投影仅使用未删除的当前有效版本，继承 DATA-01 live evidence check；没有重做 MEM-04 或接正式记忆索引。读请求收到 401/403 后，隔离 UI 隐藏已缓存时间线；此前已经合法收到的浏览器内容不是远程可擦除数据，不宣称离线撤权。
- 移动端任务详情有限高和滚动，不挤走输入区域；使用 393×852 Edge 合成场景验证，截图仅留忽略区。

## 隔离 API

统一前缀 `/api/lab/chat-data01`，全部继承 owner 登录、CSRF、Origin 及精确会话限制。

| 路径 | 行为 |
|---|---|
| POST `/bubbles/:id/operations` | edit / switch / delete / regenerate / regenerate-turn；requestId + expectedRevision |
| GET `/bubbles/:id/current?revision=N` | 核验当前来源供复制/引用/跳转；旧 revision 或已删除返回 409 |
| GET `/search?q=…` | 仅当前有效来源 |
| GET `/jobs/:id` | 受权任务状态、尝试和允许展示的部分文本 |
| POST `/jobs/:id/cancel` | requestId 幂等取消 |
| POST `/jobs/:id/retry` | requestId + acknowledgeUnknown；不自动重试或重绑定旧来源 |
| GET `/history` | 保留旧展示字段，追加权威 ops.items/versions/jobs；引用实时脱敏 |

原 capabilities/submit 保留。仅标记运行器挂载，正式 app.ts、`/chat`、`/api/chat` 不接本候选。

仍在原 SQLite 内复用 conversation/turn/revision/操作账本和候选 outbox，没有另建聊天库。v1—v4 SQL、旧 outbox、Agent 协议、ACK 与正式迁移列表未改；新数据仍未正式归档，`canPrune=false`，禁止依据旧 ACK 清理。真实工具持久事件仍独立，没有变成普通气泡。
