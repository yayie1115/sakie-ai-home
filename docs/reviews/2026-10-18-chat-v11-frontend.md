## 基线与计划

已阅读 `docs/design/chat-v11-interactive.html`、`docs/design/chat-v11-codex-handoff.md`、既有产品需求 v1.1 的 Chat/媒体/回收站规则及现有前端、后端共享聊天接口。以 v11 的新决定覆盖旧 Chat 信息架构冲突；没有复制 HTML 的脚本或将原型嵌入 iframe。

## 可访问方式与真实边界

本机已启动仅绑定回环的前端开发服务：`http://127.0.0.1:5187/demo/chat-group`。对应命令：`npm run dev --workspace frontend -- --host 127.0.0.1 --port 5187 --strictPort`。点击会话列表进入合成私聊/群聊。当前 `/chat` 真实页面及其认证/幂等 API 逻辑保持不变，尚未由 v11 替换；本次没有把全局 Chat 切成冒充真实数据的模拟页面。

此入口是可维护 React 前端候选，不是生产启用：真实角色/群聊权限、共用模型配置、多气泡发送/中断、重生成及版本持久化、完整服务器搜索、同步读旧消息时的第一条未读、真实图片横滑/原图查看、语音播放/转写、跨模块操作日志、统一回收站及记忆/媒体删除传播均尚待接口与数据层接入。媒体入口明确说明未接入，不用无声按钮假装已播放。回收站只模拟会话与 30 天内恢复，不运行真实过期清理；其他分类只是未接入状态。外观集中变量和深浅主题已完成，用户自定义色彩/壁纸设置页尚未实现。

未在真实 iPhone Safari/软键盘上验收；Edge 移动视口不是 iOS 真机。完整焦点陷阱/屏幕阅读器、很大历史量、同标签并发编辑及生产资源占用仍需后续验证。没有迁移、读取或修改正式数据库、ACL、真实备份、模型密钥、云端服务或 DNS，也没有提交/推送 Git。
