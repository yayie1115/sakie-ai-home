# Morrow / OB2 基础记忆正式上线（2026-10-28）

用户已确认 OB2 指现有 Serein。本轮停止扩展高级来源架构，只交付普通聊天记忆。

## 已上线

- Morrow 实际部署代码：`70473a30028201a924681e8d56e96aaccbe11854`；此前最小路由修正为 `602c6f5ce44809409ab4d802d5f24867d77e9fa4`。后续文档提交不代表程序又部署了一次。
- 复用现有 `serein.service`、`POST /api/hook/recall`、`/serein/mcp` 的 `read_memory`、`recall_memory`、`write_scene` 等接口。没有重装 Serein、改上游规则或开放管理接口。
- `prefer_scene_writes=true`：新记忆写工具优先使用 Serein；`replace_legacy=false`，旧 Morrow 记忆保留并继续读取。
- `explicit_text_memory_enabled=true`：用户说“请记住……”时，宿主只读取当前新文本，经现有 Scene API 和幂等账本保存，将实际回执提供给聊天；否定要求、附件、保护模式、状态未知不强行保存。失败不报告成功，不盲目重试。
- 该通道形成独立 Scene，保留 unbound 状态，不伪造原话证据、来源认证或共同经历。人格、聊天模型配置、Embedding/Reranker 和旧数据未修改。

## 使用和限制

继续使用用户刚选择的可用聊天模型。在正常聊天里说“请记住：……”，收到成功回执后，新建会话询问相应内容即可。不需要补 API 或额外部署。

当前兜底保证的是**明确要求记住的新文本**；没有声称全部普通聊天都会自动筛选、提取。模型自主调用 Scene 工具仍取决于中转是否支持结构化工具调用。原话档案、自动 Event、Aru 导入和高级来源撤回不在本轮范围；删除聊天不等同于删除独立 Scene 记忆。
