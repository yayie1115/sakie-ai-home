## 本轮实际测试

执行：`python -m py_compile scene_retractions.py serein_bridge.py auto_text_memory.py app.py`，通过。

执行：`python -m unittest discover -s tests -p test_scene_retractions.py`，**15 项通过，0 失败，1.259 秒**；只使用新建本地临时合成数据库和模拟 MCP，不访问生产数据或模型。

覆盖：

- 新写入回执的持久来源关联；写入成功回执之后、关联完成之前的崩溃恢复。
- 删除消息后、后台撤回前先阻断旧记忆读取；确认撤回后解除对应阻断。
- 跨会话两个有效来源：删一个保留，删完才撤回。
- 会话消息删除不影响未关联独立记忆；编辑、版本切换、隐藏使旧关联失效。
- 读失败重试；删除响应丢失后先查状态、不重复删除；重启后不恢复已撤回 Scene。
- 未知写入结果在来源删除后保持阻断，不猜测 Scene；仅识别已记录的旧哈希格式，不再依赖标题。
- 模型不能通过工具参数伪造宿主 origin；显式保存沿用真实回执；已撤回结果不再参与正常去重。

**未执行：**本轮完整后端回归、真实服务进程联调、HTTP 删除与摘要接口验收、原生 Serein 多来源撤回联调、实际 Event 模型任务、生产部署和启用。上轮 542 项通过不能当成本轮候选的完整回归成绩。
