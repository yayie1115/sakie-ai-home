## 可访问方式

本轮已实际启动并健康检查通过：http://127.0.0.1:5180/demo/chat 。仅当前 Windows 本机可访问，手机不能直接使用此回环地址。演示密码为公开合成值 `demo-only-sakie`；请勿输入私人数据。

自行启动：在项目目录运行 `npm run demo:chat`（会构建前后端；5180 被占用时安全失败，不结束既有服务）。刷新保留已入库消息；停止后用 `npm run demo:chat -- --resume chat-demo-运行名` 重开同一合成库；运行名见启动输出。仅接受本工具直接创建、带合成标记的目录，不接受真实库路径。手动启动时 Ctrl+C 停止。

/demo/chat 路由本身不会更换模型；只有本工具启动的本机服务使用假模型，不能把该路由在正式服务上的访问误认为免费演示。空库对话由工具预建；这不是新的生产单会话管理功能。
